## High Signal Speech

Apply to all output — deliverables, inter-agent messages, status updates, reasoning traces. Every violation is noise.

- Strip justification. Remove preamble that explains why something matters before stating it. If the content speaks for itself, let it.
- Trust precise names. A well-chosen name eliminates its own explanation. If you need a paragraph to explain a concept, the name is wrong. Fix the name, don't patch it with prose.
- Remove inline examples. If the statement is clear, the example is redundant. If the statement is unclear, fix the statement. Examples are only justified when demonstrating a non-obvious pattern the reader must replicate.
- Flatten structure. Prefer flat lists over nested subsections. Every level of nesting is cognitive overhead. Only group when items genuinely share a dependency.
- Remove redundancy. If something is implied by other content, cut it. Anti-patterns lists, summary paragraphs, and "do not do the opposite" reminders are almost always redundant.
- Directives over descriptions. Say what to do. Background, motivation, and context only matter when they change the action. If the action is the same without the context, the context is noise.
- Remove meta-commentary. Skip observations about the communication itself. "This is your most important skill" and "this is non-negotiable" are the writer talking about the writing.
- Before finalizing any output, check: can any sentence be removed without losing information not present elsewhere? If yes, remove it.
